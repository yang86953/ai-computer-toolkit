# 定位与边界

[← 文档中心](../README.md)

ai-computer-toolkit 为 AI 提供第三方软件的前台桌面控制：真实截图、键盘和指针。
默认无参数启动 MCP stdio 服务，也提供版本化 CLI。不是 UIX 应用后台控制器、浏览器内核或任务调度平台。

## 平台与依赖

Linux/Wayland 使用 XDG Desktop Portal、PipeWire 和 EIS；Windows 使用 UIX 平台能力、
WGC 与 Win32 输入执行器。两条路线均不提供后台隔离，不能用结构化树替代真实输入结果的观察。
Windows 编译/协议覆盖不等于交互桌面上的 WGC/键鼠验收；帧订阅目前按 Linux broker 的 feature 发布。

UIX 是 Cargo 清单与锁文件中的外部公开 Git 依赖；本项目不内嵌框架源码或客户端专属扩展。
工具链跟随最新 Rust stable；`rust-version` 声明最低兼容目标，不是固定当前编译器。

## 使用与安全边界

先连接，再从真实截图确定目标，执行有界输入批次，核对新的观察结果，最后显式断开并释放会话。
输入必须绑定当前有效 frame；坐标单位和时效由工具 schema 决定，不混用截图像素与相对逻辑像素。
文本键入不等于 Unicode 粘贴。长确定序列可以使用 `computer_run`，未知状态时不继续盲发。

`confirmed`、`foregroundConsent` 仅记录用户已经给出的授权；`strictIsolation=true` 不支持时明确拒绝，
不静默降低。前台焦点可能被用户或其他软件改变，短批次不是焦点隔离保证。
输入已发出而观察失败或 `OUTCOME_UNKNOWN` 时先核对现状，不自动重放。

当前可用工具、限制和错误以[主 README](../../README.md)、[MCP 契约](../computer-control-mcp.md)
及运行时能力发现为准。候选、实验、旧 UIX 控制和只为兼容而保存的 schema 不表示默认启用。
